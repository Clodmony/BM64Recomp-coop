# The stream when the session is lost (#57, docs/coop/design.md, *The
# playtest's logs*): the client's game stops early (its script ends and the
# run stops it, as in session-lost), without sending anything more. The lines
# it logged up to shortly before are in the host's
# coop-logs/<time>-client.log, and the host plays on alone.
#session
#env BM64_COOP_WARP=0x29:0x13
#
#check log "^coop: session lost frame=\d+: (the other side closed|send failed); playing alone$"
#check after "^coop: session lost" "^coop: input: alone$"
#check contains coop-logs/*-client.log "^coop: input: client marker 1$"
#check contains coop-logs/*-client.log "^coop: input: client marker 20 frames before its end$"
#check-client contains coop.log "^coop: input end$"
#
#client overlay 0x29
#client wait 100
#client log client marker 1
#client wait 80
#client log client marker 20 frames before its end
#client wait 20
#client end
overlay 0x29
wait 800
log alone
end
